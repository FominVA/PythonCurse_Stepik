Глоссарий
✅ Перегрузка методов — это прием программирования, который позволяет в зависимости от переданных в метод аргументов использовать определенную версию метода.

✅ Python не поддерживает перегрузку методов напрямую.

✅ Метод инициализации __init__() является по сути обычным методом, мы не можем его перегружать. 
Мы можем обойти это ограничение несколькими способами, имитируя несколько инициализаторов:

    Использование необязательных аргументов в методе __init__() — наиболее простой способ имитации нескольких инициализаторов в классе. 
    Это чистый и основанный на Python метод создания классов, имитирующих несколько методов инициализации.

    Использование проверки типов аргументов для обеспечения различного поведения в зависимости от конкретного типа. Данная техника плохо масштабируется и считается антипаттерном.

    Использование методов класса является эффективным методом имитации нескольких инициализаторов. 
    Это чистый и основанный на Python метод создания классов, имитирующих несколько методов инициализации.

    Создание универсальной функции одиночной диспетчеризации. 
    Данный способ позволяет определить несколько инициализаторов и выборочно использовать их в зависимости от типа первого переданного в них аргумента.

✅ Универсальная функция (generic function) представляет собой функцию, составленную из нескольких функций, реализующих одну и ту же операцию для различных типов.

✅ Одиночная диспетчеризация (single dispatch) — это алгоритм, который выбирает нужную реализацию на основе типа одного аргумента.

✅ Создание универсальной функции одиночной диспетчеризации происходит с помощью декоратора @singledispatchmethod из модуля functools, 
использование которого синтаксически схоже с использованием декоратора @property. Сначала определяется базовая реализация метода и декорируется @singledispatchmethod. 
Далее определяются альтернативные реализации метода, они декорируются с помощью @<имя базовой реализации>.register(<тип>), в который передается тип аргумента, 
по которому будет происходить выбор нужной реализации. При вызове метода нужная реализация выбирается на основе типа аргумента, следующего после self.

✅ При использовании декоратора @singledispatchmethod альтернативные реализации не должны иметь то же имя, что и базовая реализация.

✅ Имена методов, являющихся альтернативными, зачастую предваряют одним символом нижнего подчеркивания, тем самым делая их защищенными.

✅ Модуль functools также содержит декоратор @singledispatch, который позволяет перегружать обычные функции вне класса.
