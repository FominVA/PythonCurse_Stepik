Глоссарий
✅ Если в классе не определено, как будет происходить сравнение с помощью оператора ==, оно будет равносильно сравнению с помощью is.

✅ Магический метод __eq__() позволяет определить, как будет происходить сравнение на равенство. При сравнении двух объектов с помощью оператора == Python автоматически вызывает данный метод у левого операнда, передавая методу в качестве аргумента правый операнд.

✅ Магический метод __ne__() позволяет определить, как будет происходить сравнение на неравенство. При сравнении двух объектов с помощью оператора != Python автоматически вызывает данный метод у левого операнда, передавая методу в качестве аргумента правый операнд.

✅ Python автоматически реализует метод __ne__(), если метод __eq__() уже реализован. При реализованном методе __ne__() метод __eq__() автоматически не реализуется.

✅ При сравнении двух объектов с помощью оператора == Python сначала вызывает метод __eq__() у первого объекта, и если метод возвращает True или False, то этот результат становится результатом сравнения. Но если метод возвращает константу NotImplemented, Python вызывает метод __eq__() у второго объекта. Аналогично если метод второго объекта возвращает значение True или False, то этот результат становится результатом сравнения, однако если метод вновь возвращает NotImplemented, результатом сравнения становится значение False, так как первый объект не знает, как сравнивать себя со вторым как, и второй объект не знает, как сравнивать себя с первым. Именно константу NotImplemented рекомендуется возвращать в методе __eq__(), если сравнение для объектов каких-либо типов не определено.

✅ Метод __eq__(), помимо сравнения с помощью оператора ==, также вызывается при проверке на принадлежность с помощью оператора in.

✅ Магический метод __lt__() отвечает за сравнение на меньше.

✅ Магический метод __gt__() отвечает за сравнение на больше.

✅ Магический метод __le__() отвечает за сравнение на меньше или равно.

✅ Магический метод __ge__() отвечает за сравнение на больше или равно.

✅ Декоратор класса @total_ordering из модуля functools позволяет определить в классе лишь метод __eq__() и один из методов __lt__(), __le__(), __gt__() или __ge__(). Все недостающие методы декоратор определит и реализует самостоятельно.

✅ После реализации в классе операторов сравнения на больше/меньше появляется возможность сортировать экземпляры этого класса и выбирать среди них наименьший/наибольший.
